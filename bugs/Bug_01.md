## Краткое описание
Поле «Номер карты:» принимает номера карт, начинающиеся с 0, и открывает следующую
форму ввода суммы, что нарушает требование стандартов платежных систем: первая цифра в номере (так называемый MII — основной отраслевой идентификатор) указывает на платежную систему.

## Шаги воспроизведения
1. Открыть `http://localhost:8000/?balance=30000&reserved=20001`.
2. Кликнуть карточку «Рубли».
3. В поле «Номер карты:» ввести 0 в качестве первой цифры: `0123012301230123`.

## Ожидаемый результат
Поле не принимает 0 в качестве первой цифры, может появляться сообщение об ошибке.

## Фактический результат
Поле ввода принимает в качестве первого символа 0 и далее пропускает сценарий как корректный: появляется поле ввода суммы и далее можно сделать перевод (по факту такой перевод будет 100% отклонен платежным шлюзом).
