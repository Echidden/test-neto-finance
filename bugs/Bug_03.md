## Краткое описание
Если сумма перевода плюс комиссия меньше максимально доступного остатка на счете, то нельзя выполнить перевод, хотя общая сумма меньше значения доступного остатка.

## Шаги воспроизведения
1. Открыть `http://localhost:8000/?balance=30000&reserved=20001`.
2. Кликнуть карточку «Рубли».
3. В поле «Номер карты:» ввести `1234123412341234`.
4. В поле «Сумма перевода:» ввести `18000`.
5. Убедиться в появлении значения комиссии в поле «Комиссия:».
6. Нажать кнопку «Перевести».

## Ожидаемый результат
Перевод выполняется, пользователь видит алерт «Перевод 18000₽ на карту 1234123412341234 принят банком!».

## Фактический результат
Вместо кнопки «Перевести» появляется сообщение о недостатке средств на счете (хотя 18000+1800 меньше 20001).
