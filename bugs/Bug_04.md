## Краткое описание
Если в поле ввода суммы ввести 0, система обрабатывает 0 как валидную сумму, рассчитывает 0 в комиссии, и показывает кнопку «Перевести».

## Шаги воспроизведения
1. Открыть `http://localhost:8000/?balance=30000&reserved=20001`.
2. Кликнуть карточку «Рубли».
3. В поле «Номер карты:» ввести `1234123412341234`.
4. В поле «Сумма перевода:» ввести `0`.
5. Убедиться в появлении значения комиссии, равного 0, в поле «Комиссия:».
6. Нажать кнопку «Перевести».

## Ожидаемый результат
Не появляется кнопка «Перевести», нет возможности сделать перевод, возможно – отображается ошибка вроде «Сумма перевода должна быть больше 0».

## Фактический результат
Кнопка «Перевести» появляется, можно совершить перевод. После нажатия на кнопку появляется alert: «Перевод 0 ₽ на карту 1234123412341234 принят банком!».
