# Тест-кейсы F-Bank 
### ручное тестирование

**Версия приложения:** бандл index-BUH56GOL.js (из dist.zip). 

**Дата:** 20-21.05.2026. 

**Тестировщик:** Юлия Миронова. 

**Окружение:** MacOS Sequoia 15.5, Google Chrome 148.0.7778.178

**Общие условия:**

Распакован dist.zip, в каталоге dist/ запущена команда python -m http.server 8000.
Браузер открыт на вкладке http://localhost:8000/?balance=30000&reserved=20001, alert-диалоги активны.

## TestCase_01 (positive, smoke). Корректный перевод проходит полностью

| Приоритет | High |
| Задача | Проверить, что корректный сценарий перевода работает полностью: счет > карта > сумма > кнопка > alert |

**Шаги:**
1. Открыть `http://localhost:8000/?balance=30000&reserved=20001`.
2. Кликнуть на карточку «Рубли».
3. В поле «Номер карты:» ввести `1234123412341234`.
4. В поле «Сумма перевода:» ввести `500`.
5. Убедиться в появлении значения комиссии в поле «Комиссия:».
6. Нажать кнопку «Перевести».

**Ожидаемый результат:**
Шаг 5: «Комиссия: 50 ₽».
Шаг 6: alert «Перевод 500 ₽ на карту 1234123412341234 принят банком!».

**Фактический результат:** 🟢 соответствует ожидаемому.
**Файл скриншота:** /test_img/TestCase_01_Passed.png
